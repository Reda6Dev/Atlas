# مرجع المرحلة 14 — المصادر المستندة إلى الروابط المباشرة (URL-Based Source Support Reference)

> **المرحلة:** Phase 14 — URL-Based Source Support
> **الغرض:** المرجع الهندسي لدراسة وتصميم نظام تحليل وإضافة المصادر والموقع الإلكترونية مباشرةً عن طريق أدخال رابط URL.
> **الحالة الحالية:** غير موجودة حالياً في الكود القائم (Advanced / Future Feature).

---

## 1. التحديات والمتطلبات الهندسية لبناء مصدر من URL

إنشاء مصدر مانغا يعتمد على رابط موقع فقط يتطلب استيفاء المكونات البرمجية التالية:

1. **مكشاف محرك الموقع (Site Engine Detector):** التعرف على هيكل الموقع (مثل WordPress Manga themes, Madara, MangaStream, FoolSlide...).
2. **محلل المحتوى (HTML / DOM Parser):** استخراج العناوين، صور الأغلفة، قائمة الفصول، ورابط كل صفحة باستخدام محددات CSS / XPath.
3. **تجاوز حمايات الشبكة (Cloudflare / Turnstile Handling):** التعامل مع تحديات الحماية عبر المنسق المدمج `WebView` ونظام الكوكيز الداخلي.
4. **منظومة التوليد الديناميكي للمصادر (Dynamic Source Generator):** تحويل الرابط والقوالب التحليلية إلى كائن ينفذ `HttpSource` داخل Atlas.
