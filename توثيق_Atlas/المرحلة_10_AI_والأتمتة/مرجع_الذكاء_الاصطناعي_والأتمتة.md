# مرجع المرحلة 10 — الذكاء الاصطناعي والأتمتة (AI & Automation Reference)

> **المرحلة:** Phase 10 — AI & Automation
> **الغرض:** المرجع الهندسي لبناء تجريد خدمات الذكاء الاصطناعي، مساعد القراءة الذكي، والتنظيم التلقائي للمكتبة.
> **الحالة الحالية:** غير موجودة حالياً في الكود القائم (Planned / Future Feature).

---

## 1. البنية المعمارية المخططة لخدمات AI (AI Provider Abstraction)

إنشاء واجهة `AiProvider` في موديول `:domain` لعزل مزودات الذكاء الاصطناعي (مثل OpenAI, Claude, Local LLMs, On-Device Models) عن نواة التطبيق:

```kotlin
interface AiProvider {
    suspend fun summarizeChapter(chapterText: String): String
    suspend fun explainContext(mangaTitle: String, term: String): String
    suspend fun recommendManga(userHistory: List<Manga>): List<String>
}
```

---

## 2. الميزات المخططة لمساعد الذكاء الاصطناعي (Planned AI Features)

1. **مساعد القراءة وفهم القصة (Reading Assistant):**
   * ملخص القصة والأحداث السابقة قبل فتح الفصل الجديد لتنعيم تجربة القراءة.
   * شرح المصطلحات والميتا المعقدة في أعمال الفانتازيا والويب تون.
2. **التصنيف والتنظيم التلقائي للمكتبة (Smart Auto-Categorization):**
   * تحليل أوسام ووصف الأعمال في المكتبة واقتراح نقلها وتوزيعها على الفئات المناسبة تلقائياً.
3. **ضوابط الخصوصية والصلاحيات (Privacy & Security Controls):**
   * إبقاء جميع عمليات الذكاء الاصطناعي اختيارية بالكامل (Opt-in).
   * مفاتيح إدخال API Keys محفورة ومحفوظة بآمان داخل `EncryptedSharedPreferences` / `PreferenceStore`.
