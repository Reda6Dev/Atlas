# مرجع المرحلة 07 — دعم المصادر والإضافات واحترام المستخدم (Source Support & User Respect Reference)

> **المرحلة:** Phase 7 — Source Support & User Respect
> **الغرض:** المرجع الهندسي لدعم آليات المصادر والإضافات، المتاجر الخارجية (Keiyoushi)، المصادقة، واحترام صانعي المحتوى والمواقع.
> **الحالة الحالية:** متحققة ومشتغلة كلياً (Current & Working).

---

## 2. سياسة احترام المصادر وصناع المحتوى (User & Source Respect Policy)

1. **إبراز بيانات المصدر الأصلية:**
   * عرض اسم المصدر الأصلي واللغة بوضوح في شاشة تفاصيل المانغا وشاشة التصفح.
2. **توفير روابط المواقع الرسمية والدعم:**
   * زر التوجيه إلى الموقع الأصلي للمصدر عبر المتصفح الداخلي (`WebView`) أو الخارجي.
   * إتاحة روابط الدعم والاشتراك الخاصة بالمترجمين ورعاة المحتوى عند توفرها.
3. **دعم تسجيل الدخول والاشتراكات الرسمية:**
   * دعم جلب الكوكيز وتسجيل الدخول عبر `WebView` للمصادر التي تتطلب اشتراكاً أو حساباً (مثل MangaDex, E-Hentai UConfig).
4. **منع تجاوز آليات الحماية والتبرع:**
   * عدم تعديل أو تخريب آليات الدعم المالي للمصادر الأصلية.
